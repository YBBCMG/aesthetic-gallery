# 审美画廊 · Aesthetic Gallery

把「审美偏好」固化成可执行的坐标：先说清楚喜欢什么风格，再让 AI 按这套坐标干活，而不是每轮重新猜。

## 内容

| 文件 | 说明 |
|---|---|
| `index.html` | 12 种视觉风格画廊 —— 用来挑风格（选中的是粗野主义 / Bento / 编辑杂志） |
| `branches.html` | 三轴分支树 —— 粗野 6 支、Bento 6 支、编辑 6 支，外加 3 条合流线 |
| `CHARTER.md` | 定稿的审美宪章 —— 总则 / 轴 / 分支 / 禁区 / 场景 |

## 用法

纯静态，无构建、无依赖。双击 `index.html` 即可，或起个本地服务器：

```bash
npx serve .
```

## 为什么做这个

「好看」是一种没被拆开的感觉。把感觉拆成轴（粗野 / Bento / 编辑）和分支（新粗野、瑞士网格、时尚大片……）之后，
每次出方案都能报编号对齐，而不是靠「再改改」来回试。
